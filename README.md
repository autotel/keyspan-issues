# Keyspan issues

Problem reports and suggestions for [Keyspan](https://keyboard-sight-reading.kinsta.page/), graded piano sight-reading exercises generated for the keyboard you have.

The easiest way to report is the ⚑ button on any exercise or piece in the app. It opens a new issue here of the right kind, with the level, exercise number, keyboard, settings and the score already filled in, plus a link that reopens the same exercise.

You can also [open an issue](../../issues/new/choose) directly.

This repository only holds the issue forms. Keyspan's source code is not public.
